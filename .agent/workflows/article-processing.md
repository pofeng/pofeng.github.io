# 文章處理 Workflow

這個 workflow 會幫助您處理文章，包含翻譯、校正、摘要和圖片生成。

## 使用方式

在執行此 workflow 之前，請準備：
- 原始文章檔案路徑
- 目標語言（例如：英文、中文、日文等）
- 輸出目錄

## 步驟

### 1. 準備原始文章
確認您有要處理的文章檔案。可以是 `.md`、`.txt` 或其他文字格式。

### 2. 翻譯文章
使用 AI 將文章翻譯成目標語言：
- 讀取原始文章內容
- 指定目標語言
- 生成翻譯版本
- 儲存為 `[原檔名]_translated.[副檔名]`

### 3. 校正翻譯內容
對翻譯後的內容進行校正：
- 檢查語法錯誤
- 確保用詞準確
- 改善可讀性
- 儲存為 `[原檔名]_corrected.[副檔名]`

### 4. 生成摘要
從校正後的文章生成摘要（約 200 字）：
- 提取關鍵要點
- 保持原文核心訊息
- 確保摘要簡潔有力
- 儲存為 `[原檔名]_summary.[副檔名]`

### 5. 根據摘要生成圖片
使用 `generate_image` 工具根據摘要創建視覺化圖片：
- 分析摘要的核心主題
- 設計適合的視覺元素
- 生成高品質圖片
- 儲存為 `[原檔名]_image.webp`

## 輸出檔案

完成後，您將獲得以下檔案：
- `[原檔名]_translated.[副檔名]` - 翻譯版本
- `[原檔名]_corrected.[副檔名]` - 校正版本
- `[原檔名]_summary.[副檔名]` - 摘要
- `[原檔名]_image.webp` - 視覺化圖片

## 範例

假設您有一篇文章 `article.md`，執行此 workflow 後會產生：
- `article_translated.md`
- `article_corrected.md`
- `article_summary.md`
- `article_image.webp`

## 注意事項

- 確保原始文章內容清晰完整
- 翻譯品質取決於原文的結構和用詞
- 圖片生成會基於摘要的關鍵概念
- 所有檔案會儲存在與原始文章相同的目錄中
