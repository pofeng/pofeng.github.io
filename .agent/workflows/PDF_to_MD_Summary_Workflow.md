# PDF 轉 MD 與摘要生成工作流程

你是一個文件處理助手。你的任務是將 PDF 檔案轉換為 Markdown 格式，然後使用 OpenCode CLI 的 subagent 功能對產出的 MD 檔案進行摘要。

## 工作流程

### 第一階段：PDF 轉 Markdown（保留表格，跳過圖片）

**輸入目錄**：`workspace/articles/`
**輸出目錄**：`workspace/md_output/`

**處理步驟**：
1. 掃描 `workspace/articles/` 目錄下所有 `.pdf` 檔案
2. 使用 `pdfplumber` 提取每頁內容：
   - 提取文字（保留段落結構）
   - 提取表格（轉換為 Markdown 表格格式）
3. 識別章節標題，使用 `#` `##` 等標題語法
4. **跳過圖片處理**（不提取、不標註）
5. 輸出為 `.md` 檔案，檔名為原始 PDF 名稱（移除非法字元）

**表格轉換格式**：
```markdown
| 欄位1 | 欄位2 | 欄位3 |
|-------|-------|-------|
| 值1   | 值2   | 值3   |
```

### 第二階段：摘要 MD 檔案

**輸入目錄**：`workspace/md_output/`
**輸出目錄**：`workspace/final_summaries/`

**處理步驟**：
1. 遍歷 `workspace/md_output/` 下所有 `.md` 檔案
2. 對每個 MD 檔案，生成摘要

#### 混合式摘要策略
```
1. 提取關鍵資訊點（統計數據、重要結論、決策事項）
2. 識別章節結構與標題層級
3. 整理成結構化摘要
```

#### 輸出格式

```
========================
        文件標題
========================

【基本資訊】
• 檔案名稱：{filename}
• 總頁數：{page_count}
• 圖片數量：{image_count}
• 文件類型：{pdf_type}
• 主要主題：{main_topic}

【核心摘要】
{2-3段濃縮摘要，約200-400字}

【要點整理】
1. {第一要點}
2. {第二要點}
3. {第三要點}
4. {第四要點}
5. {第五要點}


【章節摘要】
{依序列出各章節的簡要內容}

【補充說明】
• 統計數據或重要數字
• 引用來源
• 待釐清事項
========================
```


3. 將摘要結果儲存至 `workspace/final_summaries/`，檔名為 `原始檔名_summary.md`

## 目錄結構

```
workspace/
├── articles/                # 輸入 - 原始 PDF
├── md_output/               # 第一階段產出 - Markdown 檔案
├── final_summaries/         # 第二階段產出 - 摘要結果
└── scripts/                 # 腳本存放位置
```

## 品質標準

- [ ] 表格結構正確，欄位對齊
- [ ] 標題層級清晰
- [ ] 摘要涵蓋文件核心內容
- [ ] 表格內容有適當摘要說明
- [ ] 輸出檔案編碼為 UTF-8

## 開始執行

1. 建立 `pdf_to_md.py` 腳本處理 PDF 轉 MD
2. 執行轉換
3. 建立 `summarize_with_opencode.py` 腳本處理摘要
4. 執行摘要生成
